# 台灣農酪產業永續發展協會 官方網站

Taiwan Dairy Sustainability Association (TDSA) Official Website

## 技術架構

- React 18 + TypeScript
- Vite 5
- Tailwind CSS (CDN)
- Noto Sans TC 字體

## 開發

```bash
npm install
npm run dev
```

## 建置

```bash
npm run build
```

## 素材放置路徑

| 素材 | 路徑 |
|------|------|
| 協會 LOGO | `public/images/logo.png` |
| 理事長照片 | `public/images/team/chairman.jpg` |
| 秘書長照片 | `public/images/team/secretary.jpg` |
| 培訓照片 1~4 | `public/images/training/training-1.jpg` ~ `training-4.jpg` |

## 頁面結構

- **首頁** — 協會簡介、九大宗旨、聯繫資訊
- **協會章程** — 章程全文逐條列出
- **協會團隊** — 理事長/秘書長卡片 + 理監事名單表格
- **會務新知** — 活動公告列表
- **人才培育** — 計畫簡介、活動花絮、歷年報告
- **影音媒體** — 媒體報導與自製影音
